# UE5 物理吊桥系统说明

## 资产与入口

- 蓝图：`/Game/PhysicsWorldDemo/Blueprints/BP_RopeBridge`
- C++ 基类：`AWorldRopeBridge`
- 共享配置：`/Game/PhysicsWorldDemo/Config/DA_WorldInteractionConfig`
- 配置脚本：`Scripts/ConfigurePhysicsWorldRopeBridge.ps1`
- 专项验证：`Scripts/ValidatePhysicsWorldRopeBridgePIE.ps1`

`BP_RopeBridge` 已放入 `Lvl_ThirdPerson`，Actor Tag 为 `PhysicsWorldRopeBridge`。蓝图是 `AWorldRopeBridge` 的可放置外壳，木板与 Constraint 由继承的 C++ `OnConstruction` 自动生成，效果等同于 Construction Script，且不会依赖易损的自动生成 K2 图。首次配置脚本负责放置，后续重复运行会保留已有 Actor Transform、共享调参和单桥 Override。

## Construction 生成结构

`Lvl_ThirdPerson` 当前演示实例为 60 块木板、4 个圆柱桥墩和 63 个 Physics Constraint：

```text
左端                                                     右端
Primary 桥墩   o--[Primary]--\                   /--[Primary]--o   Primary 桥墩
                               木板 0 -- ... -- 木板 59
Secondary 桥墩 o--[Secondary]-/                   \-[Secondary]--o Secondary 桥墩
```

约束总数按 `N + 3` 计算：60 块木板之间有 59 个板间 Constraint，首尾各有 Primary 和 Secondary 两个端点 Constraint，共 63 个。每端两个锚点位于木板横向两侧，位置公式为 `Y = +/-(Plank Width / 2 - Anchor Lateral Inset)`；当前宽度 `200cm`、内缩 `15cm`，因此锚点为 `Y = +/-85cm`，同端桥墩横向中心距为 `170cm`。

木板全部开启 Simulate Physics。板间 Constraint 锁定 Linear X/Y/Z，使用 Swing1/Swing2/Twist 限制相邻木板；相邻刚体关闭互撞，避免板缝挤压产生弹飞。端点采用两种不同 profile，避免同一端板被两套完整约束重复求解：

| 端点 profile | Linear | Angular | Projection |
|---|---|---|---|
| Primary | X/Y/Z Locked | 仅 Swing1 Limited；Swing2、Twist Free | 开启 |
| Secondary | X/Y Locked；Z Free | Swing1、Swing2、Twist 全部 Free | 关闭 |

Constraint 局部轴显式映射为 `X=Up`、`Y=桥方向`、`Z=木板宽度`。双挂点连线与局部 Z 一致，因此端板保留 Swing1 前后俯仰，同时由两点几何约束抑制横滚和水平扭转。桥面初始带 `Bridge Sag`，为两端锚定的长链保留下沉和摆动余量。

## 常用参数

以下为 `Lvl_ThirdPerson` 当前桥实例的 Override 值；共享默认值仍位于 `DA_WorldInteractionConfig -> Settings -> Rope Bridge`：

| 参数 | 当前值 | 作用 |
|---|---:|---|
| `Plank Count` | 60 | 木板数量；至少 12，Constraint 数量自动为 N+3 |
| `Plank Width / Depth / Height` | 200 / 25 / 6cm | 单块木板尺寸；当前桥面约 `16.77m x 2.00m` |
| `Plank Gap` | 3cm | 板间视觉和碰撞间隙 |
| `Bridge Sag` | 120cm | 初始下垂和可摆动余量 |
| `Anchor Extension` | 60cm / 端 | 首尾板中心到桥墩顶部锚点的纵向距离 |
| `Anchor Lateral Inset` | 15cm | 锚点从木板左右边缘向内缩的距离；当前得到 `Y=+/-85cm` |
| `Minimum Anchor Separation` | 10cm | 防止同端两个锚点重合或接近重合的稳定性下限 |
| `Support Radius / Height` | 30 / 220cm | 4 个圆柱桥墩的半径与高度 |
| `Plank Mass Kg` | 15kg | 单板惯性和承重手感 |
| `Swing1 Limit Degrees` | 10deg | 沿桥方向前后俯仰范围 |
| `Swing2 Limit Degrees` | 2deg | 板间侧向滚转范围；端点 Primary/Secondary 不消费该限制 |
| `Twist Limit Degrees` | 0deg | 板间水平扭转，0 表示锁定；端点角向 Twist 为 Free |
| `Linear Damping` | 1.5 | 平移衰减速度 |
| `Angular Damping` | 4.0 | 摆动和旋转衰减速度 |
| `Projection Linear / Angular Alpha` | 0.15 / 0.0 | 板间与 Primary 的误差修正；Secondary 强制关闭 Projection |
| `Projection Linear / Angular Tolerance` | 2cm / 10deg | Projection 进入强修正前的容差 |
| `Position / Velocity Solver Iterations` | 32 / 8 | 60 板长链的推荐求解迭代 |
| `Max Angular / Depenetration Velocity` | 240deg/s / 200cm/s | 限制异常旋转和穿透修正速度 |

角色载荷位于同一结构的 `Character Load` 分类：

| 参数 | 当前值 | 作用 |
|---|---:|---|
| `Minimum Movement Speed` | 25cm/s | 低于该速度不产生额外脚步冲量 |
| `Movement Reference Speed` | 600cm/s | 脚步冲量达到上限时的参考速度 |
| `Movement Impulse At Reference Speed` | 90 | 参考速度下的单次脚步冲量 |
| `Movement Impulse Interval` | 0.20s | 连续移动时的脚步冲量间隔 |
| `Minimum Jump Takeoff Speed` | 120cm/s | 识别主动起跳的最小向上速度 |
| `Jump Takeoff Impulse Scale / Max` | 0.004 / 250 | 起跳动量传给脚下木板的比例和上限 |
| `Minimum Landing Speed` | 180cm/s | 识别有效落地的最小下落速度 |
| `Landing Impulse Scale / Max` | 0.006 / 500 | 落地前动量传给木板的比例和上限 |
| `Character Tracking Height` | 450cm | 保持空中角色采样、用于识别落地的查询高度 |

移动冲量随水平速度连续增长；起跳和落地按 `角色质量 x 垂直速度 x Scale` 计算并受 Max 限制。以上手感值仍为 `[PLACEHOLDER]`，应结合最终桥长、角色速度和镜头表现继续调。

单独调整某一座桥时，在关卡选中 `BP_RopeBridge`，开启 `Rope Bridge -> Config -> Override Shared Settings`，然后修改展开的 Override Settings。修改 Actor 参数会重新执行 Construction；直接修改共享 DataAsset 后，可移动一下 Actor 或点击 `Rebuild Bridge` 刷新场景组件。

`ConfigurePhysicsWorldRopeBridge.ps1` 默认只负责资产、蓝图和关卡装配校验，不会重写调参，也不会关闭已有实例的 Override。`-PlankCount N` 只修改当前实例的木板数并保留其他 resolved settings；`-ApplyLongBridgeTuning` 会套用当前四挂点宽桥的完整稳定预设并把数量设为 60。两个参数同时使用时，显式的 `-PlankCount` 最后生效，因此也可在宽桥预设上测试其他板数。当前实例推荐用明确的成对命令复现：

```powershell
powershell -File Scripts/ConfigurePhysicsWorldRopeBridge.ps1 -PlankCount 60 -ApplyLongBridgeTuning
```

显式运行 `ConfigurePhysicsWorldRopeBridge.ps1 -ApplyLargePreset` 只会恢复共享 DataAsset 的 15 板大桥预设；已有实例 Override 不会被覆盖。

## 调参方向

- 想让桥更晃：提高 `Bridge Sag` 或 Swing1，降低 `Plank Mass Kg`、Angular Damping。
- 想让桥更稳：提高 `Plank Mass Kg` 或 Angular Damping，降低 Swing1。
- 想拉开桥墩：提高 Anchor Extension；没有绳索视觉模型时不要让桥墩内缘与首尾板留下过大的可见断口。
- 想调整同端桥墩横向距离：降低 `Anchor Lateral Inset` 会把挂点向木板边缘外移，提高该值会向中心收拢；不要让结果低于 `Minimum Anchor Separation`。
- 想让离开后更快停：优先提高 Angular Damping，每次增加 `0.25~0.5`。
- 想放大跑动差异：提高 Movement Impulse At Reference Speed；频率不够时再降低 Movement Impulse Interval。
- 想让起跳蹬板更明显：提高 Jump Takeoff Impulse Scale 或 Max；出现弹飞时先降低 Max。
- 想让落地更重：提高 Landing Impulse Scale；普通走下小台阶也触发时提高 Minimum Landing Speed。
- 出现板间拉开：提高 Position Solver Iterations，随后小幅提高 Projection Linear Alpha。
- 出现端板高频抖动：先确认每端只有 Primary 开启 Projection，Secondary 必须保持 Projection 关闭且 Linear Z Free。
- 不要把板间或 Primary 的三条 Linear 轴改为 Free；Secondary 的 Z Free 是用于消除双挂点冗余约束的固定设计。

## 角色与现有交互系统

角色站立下压力来自 `DA_RoverMovementConfig` 中的 `Physics Interaction Character Mass Kg=100` 和 `Standing Downward Force Scale=1.0`。吊桥用一个 Query Only 体积追踪附近 `ACharacter`，只在角色的 Movement Base 确实属于本桥木板时加力：水平速度生成周期脚步冲量；`JumpCurrentCount` 确认 CharacterMovement 接受跳跃后，离开木板且向上才生成起跳蹬踏冲量；重新获得木板 Base 时使用落地前垂直速度生成更大的落地冲量。后续摆动完全由 Chaos、Constraint 和 Damping 演算。

吊桥不实现 `UPhysicsInteractable`。现有 `UWorldInteractionSubsystem` 已会向命中的 Simulating Physics 木板提交近战或爆炸冲量，再实现接口加力会造成双重冲量。

## 本轮验证状态

四桥墩、四端点约束版本已通过 `ValidatePhysicsWorldRopeBridgePIE.ps1` 专项 PIE，并通过 `ValidateRoverPIE.ps1` 基础角色回归。验证覆盖空载稳定、中央受控冲量、真实角色站立/走跑/起跳/落地、离桥后的阻尼衰减、四挂点 Frame 误差和板间距离误差。

本轮实测：

- 结构：60 块木板、63 个 Constraint、4 个桥墩，Primary/Secondary 挂点 `2/2`；
- 尺寸与质量：约 `16.77m x 2.00m`，每板 `15kg`；
- 走/跑脚步冲量：`23.3 / 63.2`；起跳/落地冲量：`241.1 / 366.1`；
- 角色加载期间桥中心最大附加下沉：`15.2cm`；
- 四端点最大 Frame 分离误差：`0.56cm`；最大板间距离误差：`0.45cm`；
- 角色离桥后恢复：`0.0cm/s / 0.0deg/s`；
- 未出现 NaN、约束断裂、持续能量增长、端板高频抖动、塌桥或木板弹飞。
