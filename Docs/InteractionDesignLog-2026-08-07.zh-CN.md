## 今日目标

今天没有继续增加战斗招式，而是把一个小型 Physics Constraint 样例推进为开放区域中的**动态通行节点**。

这座桥需要回答四个玩家体验问题：

1. 它是否一眼像一条能走的桥，而不是一排悬空方块；
2. 角色重量和速度是否能被桥面读出来；
3. 玩家离开后，桥是否会自然恢复而不是停在歪斜状态；
4. 攻击、移动和跳跃是否各自产生符合直觉的反馈，不互相串扰。

## 体验规则

吊桥不增加新按键。玩家只通过现有行为与它沟通：

| 玩家行为 | 设计目标 | 当前判断 |
|---|---|---|
| 站立 | 有持续承重，但不重复制造脉冲 | 已接入 |
| 行走 | 轻微、连续、可察觉 | 已接入 |
| 奔跑 | 明显强于行走 | 输入层级成立 |
| 起跳 | 离板时给桥一个清楚的反作用 | 仍需增强表现 |
| 落地 | 成为最主要的垂直冲击 | 尚未达到最终目标 |
| 攻击 | 不应比落地更强烈地扰动桥面 | 当前未通过 |
| 离开 | 余振衰减并回到自然弧线 | 已通过结构验收 |

“落地最强”是当日设计目标，不是 2026-08-07 已实现的结论。当日测试中攻击峰值仍高于落地，因此本日志记录的阶段状态是结构完成、手感调优中；后续完成状态见文首说明。

## 从组件样例到动态路径

桥体经历了四步迭代：

1. 取消木板数量硬上限，将原型扩展到 `60` 块；
2. 将桥面加宽到 `4m`，并在两端设置四个可见桥墩 / 挂点；
3. 把每道板缝的中轴单关节改为左右双侧关节；
4. 增加离桥自然姿态恢复和角色行为载荷分层。

## 为什么中轴关节不适合这座宽桥

木板刚体始终围绕质心求解，但约束施力点会决定力矩。宽木板只有一个中轴关节时，角色踩在一侧形成的横向力臂没有第二个挂点抵抗，长链很容易积累成麻花状横滚。

当前每道板缝采用互补的两条约束线：

- **主约束**：Linear XYZ Locked，只保留有限 Swing1，负责链长与前后俯仰；
- **稳定约束**：Linear XY Locked、Z Free，Angular 全 Free，用第二个受力点稳定横滚；
- **两侧位置**：`Y=+/-185cm`，专项检查横向误差为 `0.000cm`。

副约束如果再复制一套完整锁定，会让两个求解器目标互相争抢。释放冗余自由度后，桥面获得双侧受力，却不会被强行变成刚性平台。

## 角色载荷与恢复规则

- 角色使用约 `100kg` 质量形成持续站立载荷；
- 行走和奔跑按水平速度周期生成向下脚步冲量；
- 起跳由 `JumpCurrentCount` 确认，避免把普通离板误判为跳跃；
- 落地保留空中最大下落速度，避免 CharacterMovement 在落地帧清零垂直速度；
- 起跳和落地冲量按 `0.6 / 0.2 / 0.2` 分配给脚下板及前后相邻板；
- 离桥后等待 `0.5s`，再用 `1.0s` 渐入恢复自然弧线；
- 姿态误差低于 `2deg` 且角速度低于 `5deg/s` 后，停止恢复驱动并进入 Chaos Sleep。

动态基底上的攻击推进和 CharacterMovement Push Force 均设为 `0`，持续站立载荷保持 `1`。这样攻击不会通过主动前冲或突然卸载直接给桥面注入能量。

## 攻击异常的当前判断

Attack01 的峰值稳定出现在 Recovery 阶段约 `0.83s`，不是武器 Active 命中时刻。已经排除：

- 武器或角色网格直接物理碰撞；
- 世界交互请求重复加力；
- 攻击推进 Root Motion Source；
- 动画 Root Motion；
- CharacterMovement Push Force；
- 角色主动相对脚下木板移动；
- 首次资源加载卡顿。

攻击时角色相对木板位移为 `0cm`，世界位移约 `46.7cm`，说明角色是被桥面带动。下一步重点检查 Recovery 状态切换前后的 Movement Base、CurrentFloor 与持续站立载荷更新。

当前专项脚本虽然输出 `PIE_OK`，但还没有攻击峰值失败阈值。因此它只能证明结构和流程运行完成，不能代表攻击体验已经验收。

## 镜头控制权

物理场景需要玩家持续观察局部反馈。移动停止后自动把镜头拉回角色背后会打断判断，因此关闭自动回正。最新相机专项最大 Yaw 漂移为 `0.00deg`，保留玩家选择的观察方向。

## 下一轮出口标准

1. 给攻击峰值增加自动失败阈值；
2. 让攻击响应不高于落地，并接近同等时长的站立对照；
3. 用统一桥体响应指标重新验证站立、走、跑、起跳和落地；
4. 在机制正确后，再调起跳 / 落地速度映射，避免固定冲量感；
5. 补充火球 / 爆炸作用于吊桥和多桥同时运行的压力测试；
6. 最后再补绳索、护栏、材质与声音，不用美术效果掩盖规则问题。
