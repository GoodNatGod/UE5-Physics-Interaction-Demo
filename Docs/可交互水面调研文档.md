# 可交互水面调研文档 — UE5.8 插件 / 资产 / 自制方法对比

> **用途**：作为 Codex 实现"可交互水面"的输入文档。先读 §1 明确目标，再读 §5 推荐路线，§6 是可直接执行的实施规格。
> **项目**：鸣潮复刻（UE 5.8，写实 PBR 渲染路线——鸣潮原作风，非卡通渲染，单人第三人称动作）
> **版本**：0.1.0 · 2026-08-08

---

## 1. 目标定义：本项目"可交互水面"要做什么

参考鸣潮实际效果，按优先级：

| # | 交互需求 | 说明 | 优先级 |
|---|---------|------|:--:|
| 1 | **涉水涟漪** | 角色走入浅水，脚下持续产生扩散涟漪圈 | P0 |
| 2 | **鸣潮式水面材质** | 写实 PBR 基底：深度吸收双色、折射 + 反射、岸线/障碍物边缘泡沫、焦散投射、双层法线扰动 + 微 WPO 起伏（对标鸣潮原作实机效果，**非卡通色阶**） | P0 |
| 3 | **入水/出水水花** | 跳跃落水、冲刺入水的飞溅粒子 + 大涟漪 | P0 |
| 4 | **游泳** | 水深过胸切换泳姿（移动系统已预留 `ERoverLocomotionState::Swimming`） | P1 |
| 5 | **攻击/技能水花** | 攻击命中水面时溅射 + 涟漪脉冲 | P1 |
| 6 | **元素反应** | 火打水→蒸汽、电打水→感电区域（`EWorldElementType::Water` 已存在，鸣潮核心玩法） | P2 |
| 7 | **道具浮力** | 木箱等物理道具漂浮（已有 `PhysicsInteractable` / `WorldDestructibleBox`） | P2 |

**明确不做**（本期范围外）：开放世界海洋、真实波浪模拟（Gerstner 大浪）、多人同步、移动端。

## 2. 项目现状盘点（实现时直接复用的钩子）

| 已有设施 | 位置 | 与水面系统的关系 |
|---------|------|----------------|
| 游泳状态枚举 | `RoverLocomotionTypes.h` → `Swimming` | `RoverLocomotionComponent::UpdateLocomotionState` 已把 `MOVE_Swimming` 映射到该状态；只需让角色进入 PhysicsVolume 水体积即可触发 |
| 水面物理材质 | `Config/DefaultEngine.ini` → `SurfaceType5 = Water` | 水面/水底网格挂 PhysicalMaterial(Water)，攻击命中 Trace 即可识别"打中的是水" |
| 元素交互系统 | `WorldInteractionTypes.h` → `EWorldElementType::Water`；`WorldInteractionSubsystem`（`FWorldInteractionRequest/Result`） | 元素反应（蒸汽/感电）走既有 Request 管线，水面只需注册为 Receiver |
| 物理道具接口 | `PhysicsInteractable.h`、`WorldDestructibleBox` | 浮力挂到同类接口上 |
| 架构约定 | `AGENTS.md` §4 | 新逻辑进组件（与 Locomotion/Combat 平级）、数值进 Config DataAsset、PIE 验证脚本兜底 |

## 3. 候选方案清单

### 3.1 官方插件（免费，引擎内置）

| 插件 | 状态 | 提供什么 | 局限 |
|------|------|---------|------|
| **Water**（水体插件） | Experimental（UE4.26 起，成熟但更新慢） | Water Body Ocean/Lake/River/Custom（样条定义水体，自动挖 Landscape）、WaterMesh 网格系统、WaterWaves 资产（Gerstner 波）、配套水材质、`BuoyancyComponent` 浮力（独立 Buoyancy 插件） | 自带交互仅支持"脚本涟漪/船尾迹"级别；社区公认泡沫/岸线效果难调（官方论坛有"Abandoned Water Plugin"吐槽帖）；默认材质需按鸣潮原作效果重写 |
| **Water Advanced**（UE5.6 新增） | **Experimental，官方明确 Not Production Ready**（Epic 的 Devon Penney 开发，巫师4 技术演示同款） | `ShallowWaterRiverActor`：把 Water Body River 样条变成 Niagara 2D 流体模拟（可烘焙降成本）；**Shallow Water Subsystem**：注册任意 Actor 与水面交互；**角色模拟涟漪**（官方教程见 §7） | 无正式文档，只有社区教程；实验性质，5.8 上 API 可能变 |
| **Niagara Fluids** | Experimental | 2D/3D 网格流体模板（浅水、水花 2.5D Splashes、烟雾火焰）、Niagara Data Channel 供源、Niagara Baker 烘焙 | 偏 VFX 工具箱，需要自己拼装成"系统"；性能开销需实测 |

> 三者关系：Water 是"水体放置与渲染"基础；Water Advanced 和 Niagara Fluids 是"交互模拟"层，官方方向是把交互做进 Water Advanced（浅水子系统）。

### 3.2 Fab 付费资产

| 资产 | 交互能力 | 与本项目匹配度 | 备注 |
|------|---------|---------------|------|
| **Fluid Flux** | 浅水流体方程（SWE）实时模拟：河流、瀑布、海岸线、角色涟漪求解器（跟随角色、开销极小）、自带游泳/浮力组件、Niagara 异步回读采样水面高度 | 功能最强，但写实向 + 大量用例是海洋/河流；本项目只需要"池塘级"交互；**不支持开放世界、多人部分支持、无移动端、与官方 Water 插件不集成** | 价格约 $300 档（以 Fab 页面为准）；地狱之刃2 同款；买它=买一整套写实水系统，对本项目过重 |
| **UIWS**（Unified Interactive Water System） | 老牌交互水体：角色涟漪、浮力、水下、体积切割 | UE4 时代起家，5.x 持续更新；交互能力对口但同样是写实向 | 价格以 Fab 为准；教程多（B站有中文全套） |
| **Waterline PRO 6** | 海洋级：无限海洋、多级 Cascade、浪花/泡沫 VFX | 面向海洋大场景，本项目用不上 | 个人/专业分级授权 |
| **Oceanology / Riverology** | 海洋/河流物理与渲染 | 同上，场景级过重 | — |
| **Interactive World**（聆枫LingFeng，国人开发） | 雪/泥/**水**/植被通用交互画板（RT 绘制 + 风场），支持游泳、跟拍对象 | 思路与 DIY 方案一致（画板 RT），中文文档、有 GitHub 源码可参考 | 价格便宜（以 Fab 为准）；当参考资料价值 > 直接集成价值 |

### 3.3 自制方法（无插件依赖）

| 方法 | 原理 | 成本/风险 |
|------|------|----------|
| **A. RT 波动方程涟漪**（推荐） | 一张 RenderTarget 做高度场：每帧跑 2D 波动方程（前一个 RT 卷积传播 + 衰减），交互点（脚踩、落水、攻击）向 RT 写入"激波"；水材质把高度转法线叠加 | 业界标准做法（VMonty 单 RT 方案、Minions Art 教程体系）；全 Blueprint + 材质即可起步，后续可升级 Compute Shader / CustomRenderPass 优化 |
| **B. Niagara 粒子→RT** | 交互点 Spawn 涟漪粒子（环形网格或贴花），粒子渲染到 RT 再转法线 | 比 A 更简单，涟漪形状可用贴图精确控制（方便对标鸣潮原作的涟漪形态），配合 A 使用 |
| **C. SceneCapture 深度写入** | 顶视角 SceneCapture2D 把涉水物体画进 RT | 开销大（多渲染一遍场景）；知乎有 CustomRenderPass 优化方案，P2 再考虑 |
| **D. 水面材质**（必做，写实 PBR） | Single Layer Water 或 Translucent 着色：深度吸收双色（浅水暖/深水冷）+ 双层平移法线扰动 + SceneDepth/PixelDepth 与 DistanceToNearestSurface 双遮罩生成岸线泡沫 + Voronoi 焦散（经 `ColorScaleBehindWater` 投射到水下物体）+ 折射（Pixel Normal Offset）+ 反射（Lumen/SSR/平面反射按预算选）+ 小振幅正弦/Gerstner WPO 起伏 | 80.lv《Nimue 水 Shader》的技术栈大部分直接适用（§7），去掉其卡通色阶即可；SLW 模式下 Lumen 反射被强制为镜面反射（Roughness 失效）——鸣潮原作水面偏镜面反射，正好可用；需要粗糙反射再换 Translucent 路线 |

## 4. 方案对比与选型

| 维度 | 官方 Water + Water Advanced | Fluid Flux | UIWS | 全自制（A/B/D） |
|------|:-:|:-:|:-:|:-:|
| 成本 | 免费 | ~$300 | ~数十$ | 免费 |
| 鸣潮画风匹配 | 默认材质偏写实但需按原作调校 | 写实向，画风匹配（但功能过剩） | 写实向，匹配 | **可精确对标原作** |
| 角色涟漪交互 | Water Advanced 直接给（Experimental） | 内置求解器 | 内置 | 自写（工作量 1-2 天） |
| 游泳 | 自带 Buoyancy/体积方案 | 自带组件 | 自带 | 用 CharacterMovement `MOVE_Swimming`（项目已接好状态） |
| 元素反应扩展 | 自己接（正好走 WorldInteractionSubsystem） | 需反向 hack 其模拟域 | 需 hack | **天然可控** |
| 维护风险 | Water Advanced API 可能变 | 付费依赖 + 无 Water 插件集成 | 付费依赖 | 无依赖 |
| 性能 | 可烘焙 | GPU 开销中等 | 中 | RT 一张 512²，开销极小 |

**结论**：本项目（写实 PBR 画风、单池塘级水体、已有元素系统、团队已证明能自研底层）→ **官方 Water 插件做水体放置 + 自制鸣潮式材质与涟漪交互**。选型理由不是画风（写实类资产画风都匹配），而是：① 只需池塘级交互，Fluid Flux 的河流/海洋模拟过剩且与 Water 插件不集成；② 元素反应要接自有 WorldInteractionSubsystem，自制路径无黑盒；③ 免费且无付费依赖。Water Advanced 作为"先试用的免费午餐"（其 Niagara 角色涟漪是写实效果，贴合原作；满足则可少写模拟代码），Fluid Flux 仅在未来需要河流/瀑布级模拟时再评估。

## 5. 推荐路线（分期）

| 期 | 内容 | 验收标准 |
|---|------|---------|
| **P0** | 启用 Water 插件放 WaterBodyLake；自写鸣潮式写实水材质（§3.3-D）；RT 涟漪系统（§3.3-A/B）：角色移动时脚下持续涟漪、落水时大涟漪+水花粒子 | PIE 验证：角色下水行走产生跟随涟漪；从高处落水触发一次性强涟漪；材质泡沫线贴合岸边 |
| **P1** | 游泳：水体积（PhysicsVolume）+ 既有 Swimming 状态链路；攻击命中水面（SurfaceType5）触发溅射粒子 + 涟漪脉冲 | 深水自动切泳姿、出水回 Grounded；攻击打水有反馈 |
| **P2** | 元素反应：WorldInteractionSubsystem 注册水面 Receiver（火→蒸汽 VFX、电→范围感电）；道具浮力（BuoyancyComponent 挂 PhysicsInteractable）；性能优化（CustomRenderPass 替换 SceneCapture） | 元素 Request 命中水面产生对应反应；木箱漂浮 |

## 6. P0 实施规格（Codex 可直接执行）

### 6.1 插件启用（`.uproject` 追加）

```json
{ "Name": "Water", "Enabled": true },
{ "Name": "Buoyancy", "Enabled": true },
{ "Name": "Landmass", "Enabled": true },
{ "Name": "WaterAdvanced", "Enabled": true }   // 可选：先试官方角色涟漪；不满足再自写
```

> Water 插件依赖 Landmass / Niagara / GeometryProcessing / BlueprintMaterialTextureNodes，引擎会级联启用。全部在引擎 `Engine\Plugins\Experimental\` 下，源码引擎 `D:\unreal\UE_5.8` 已包含，无需下载。启用后需 `BuildEditor.ps1` 重编。

### 6.2 资产目录约定（沿用项目结构）

```
Content/Rover/Water/
  Materials/
    M_RoverWater.uasset            // 鸣潮式写实主材质（SLW 或 Translucent；参数化：深浅双色/泡沫宽/法线速度/折射/焦散）
    MI_RoverWater_Lake.uasset      // 湖泊实例
    MF_RoverRipple.uasset          // 材质函数：RT 高度 → 法线/泡沫叠加
    M_RoverRippleWrite.uasset      // 写入 RT 的激波材质（径向衰减环）
  Simulation/
    RT_RoverWaterRipple.uasset     // RenderTarget2D，512×512，R16F，跟随角色
    MPC_RoverWater.uasset          // MaterialParameterCollection：RT 世界原点/尺寸、全局波参数
  FX/
    NS_RoverWaterSplash.uasset     // 入水水花（一次性）
    NS_RoverWaterRippleRing.uasset // 可选：环形涟漪粒子（方法 B）
  DA_RoverWaterConfig.uasset       // 见 6.3
```

### 6.3 C++ 侧（遵守 AGENTS.md §4 约定）

```
URoverWaterConfig : UPrimaryDataAsset          // 数值全进 Config，禁硬编码
  ├── RippleResolution (512)、RippleWorldSize (2000cm)
  ├── RipplePropagationSpeed / Damping [PLACEHOLDER]
  ├── WalkRippleInterval (0.25s)、WalkRippleStrength
  ├── LandSplashMinImpactSpeed、SplashStrengthScale
  └── WaterlineFoamWidth、CausticsIntensity 等材质默认值

URoverWaterInteractionComponent : UActorComponent   // 挂 ARoverCharacter，与 Locomotion 平级
  ├── 每 WalkRippleInterval 检测：角色 Z 是否在水面 ±阈值内（LineTrace 或读 WaterBody 高度）
  ├── 满足 → 向 RT 写激波（UKismetRenderingLibrary::DrawMaterialToRenderTarget，位置=角色世界坐标→RT UV）
  ├── 监听 LocomotionComponent::OnLanded → 落水冲击（ImpactSpeed 缩放强度 + Spawn NS_RoverWaterSplash）
  └── 水深查询接口：供 Locomotion 判断"够深→切游泳"（P1 用，P0 先打桩）
```

### 6.4 涟漪模拟核心（材质/蓝图均可起步）

```
每帧（蓝图 LevelBlueprint 或 Actor Tick，P2 可升级 Compute Shader）：
  RT_new = 波动方程(RT_prev)：四邻平均×2 − 上帧 + Damping 衰减
  （两张 RT ping-pong，或用 Water Advanced 的浅水子系统替代此段）
交互写入：DrawMaterialToRenderTarget(M_RoverRippleWrite, 位置/强度由 MPC 传入)
材质采样：MF_RoverRipple 读 RT → HeightToNormal → 与双层平移法线叠加 → M_RoverWater.Normal
RT 跟随：RT 世界原点 = 角色位置 − RippleWorldSize/2，写入 MPC；材质里做世界坐标→UV 反算
```

### 6.5 验证（沿用项目 PIE 脚本模式）

- 新增 `Scripts/ValidateRoverWaterPIE.ps1` + `validate_rover_water_pie.py`：
  1. 加载测试地图（放一个 WaterBodyLake）；
  2. 断言 `URoverWaterInteractionComponent` 存在、RT 非空且每帧被写入；
  3. 传送角色入水 → 断言产生了激波写入（读 RT 像素或计数器）；
  4. 高处落水 → 断言 Splash Niagara 被 Spawn。
- 手感类验收（泡沫线形态、涟漪速度）仍需人眼 PIE，脚本只兜底回归。

### 6.6 明确不做 / 风险

- Water Advanced 是 Experimental：若其浅水子系统在 5.8 上不可用，直接走 §6.4 自写波动方程，不阻塞。
- SLW 着色 + Lumen：反射强制镜面（官方已知行为）——鸣潮原作水面偏镜面反射，可接受；若要粗糙反射需关 Lumen 反射或换 Translucent。
- RT 跟随角色的边缘接缝：UV 超出处 clamp + 淡出。
- Landscape 挖坑（WaterBody 会改 Landscape）：测试地图单独建，别动 ThirdPerson 主图。
